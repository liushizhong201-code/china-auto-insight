# 降幅从哪里来？第2版

[查看第2版在线项目](https://liushizhong201-code.github.io/china-auto-insight/v2/)

第2版保留70个持续可比车系、2026年1—7月累计对比2025年同期的正式口径，不修改仓库根目录的第1版。

本次调整包括：

- 将装饰性英文界面词改为中文，保留AutoLink、SUV、MPV和ID等专名或行业通用缩写；
- 将第一屏探索式提问改为结论，并明确价格带结论受归类规则影响；
- 为月度、能源、级别和指导价图表补充累计规模、变化量、同比、样本占比或净降幅贡献；
- 将最后一屏改为数据验证证据链，展示样本形成、重复获取、字段质量、内部回算和跨来源核对；
- 保留70车系搜索、筛选、排序、价格规则切换和能源×级别矩阵交互。

## 结论范围

页面解释70个持续可比车系的样本内部变化，不外推中国乘用车全市场。AutoLink页面标注数据来源易车；乘联分会只用于官方累计总量旁路对账，汽车之家只用于同名车系交叉核对，不与AutoLink相加或调平。
